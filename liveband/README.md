# LiveBand (working name)

An AI band, orchestra and choir for live events, in any musical culture. It plays whole
events, reacts to live commands like a real bandleader (natural stops, musical
mid-song switches, vamps, cues), and lets users build their dream band from the traits
of consenting, paid talent, or from scratch.

## Status

**Specification stage.** No code or deployments yet. Open questions for the owner are
in [docs/OPEN_ITEMS.md](docs/OPEN_ITEMS.md).
