# Decisions

Every decision that shapes WindWise, with the reason it was made and who made it. **Append, never
rewrite.** If a decision is reversed, add a new entry that supersedes the old one and mark the old
one `SUPERSEDED BY D-nn` — the history is the point.

Legend for **Source**: `owner` = Mayer decided it · `handoff` = fixed by `docs/HANDOFF.md` ·
`agent` = an agent's judgement call, still open to the owner's override · `evidence` = forced by
something observed (an API response, a portal screenshot, a pricing page).

## B. Technical

| #    | Decision                                                                                             | Source   | Reason                                                                                                                                                                                                                                                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-15 | Data comes from the **AccuWeather API**, not page scraping or manual upload                          | owner    | Scraping is unreliable (script-loaded content, blocks automation). Manual upload works but needs a download every time. The API is automatic                                                                                                                                                                                     |
| D-16 | **React** client + **Node** server, **TypeScript** on both                                           | owner    | The owner's choice of stack                                                                                                                                                                                                                                                                                                      |
| D-17 | **No database** in v1                                                                                | owner    | Not needed; nothing is persisted between requests                                                                                                                                                                                                                                                                                |
| D-18 | The API key lives **only on the server**; the browser never calls AccuWeather                        | owner    | A key needs a server to hold it. Acceptance criterion 7 checks this                                                                                                                                                                                                                                                              |
| D-19 | PDF is rendered **on the server** with `@react-pdf/renderer`                                         | handoff  | Deterministic pagination; the one-page guarantee can be asserted and retried before anything is returned                                                                                                                                                                                                                         |
| D-20 | Cache is an **in-memory LRU**, not Redis                                                             | handoff  | No DB in v1. A single Render instance makes a shared cache pointless. TTLs in `apps/server/src/cache.ts`                                                                                                                                                                                                                         |
| D-21 | A **`trial` tier** exists, mapping to Elite capabilities (15-day, 120-hour, alerts) at 500 calls/day | evidence | The owner's portal screenshots (Sep 24, 2026) state the 14-day trial is "Full access to Core Weather **Elite**". An earlier agent had guessed the trial equalled Starter (5-day, no alerts), which would have thrown away most of what the key can do. Superseded that guess                                                     |
| D-22 | The daily-forecast call **steps down** through 15 → 10 → 5 → 1 day windows on a 401/403              | agent    | Daily is the one call a report cannot do without. If `ACCUWEATHER_TIER` claims more than the key allows (easy to misconfigure; likely when the trial lapses), the report degrades instead of failing outright. Only a plan refusal steps down — every other error still surfaces, so real outages are not masked as narrow plans |
| D-23 | `free` stays the **default** tier                                                                    | agent    | An under-asking default degrades gracefully; an over-asking default fails. Deployments name their real plan explicitly                                                                                                                                                                                                           |
| D-24 | Hourly data is used for 4-period rows only when it spans **≥72 hours**                               | handoff  | A 12-hour window cannot fill Morning/Afternoon/Evening/Overnight across a multi-day range, so those plans fall back to Day/Night                                                                                                                                                                                                 |
| D-25 | Missing periods are **listed in the data-gaps note**, never invented                                 | owner    | Acceptance criterion 5. Fabricated weather is worse than absent weather                                                                                                                                                                                                                                                          |
| D-26 | This branch has **its own history** and is never merged into `main`                                  | agent    | `main` is an unrelated project. Git refuses to merge unrelated histories by default, so the separation is enforced mechanically, not by convention                                                                                                                                                                               |
